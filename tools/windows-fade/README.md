# S-кривая 4 с для Windows

Автономная программа для Windows 10/11 x64. FFmpeg встроен, интернет для обработки не требуется.

1. Распакуйте программу в постоянную папку и запустите `S-curve-4s.exe`.
2. Перетащите одну папку с музыкой в окно либо выберите через «Обзор» или из списка шести последних папок. Файлы и несколько папок одновременно не принимаются. Последняя папка предлагается автоматически.
3. Нажмите «Обработать». Иконка встроена непосредственно в EXE — запускайте сам файл приложения.
4. Дождитесь завершения. Готовые треки появятся в подпапке `S-кривая 4 с` выбранной папки. В `Отчёт.txt` указаны результаты и ошибки.

Поиск идёт только в выбранной папке. Подпапки пропускаются. При повторном запуске создаётся `S-кривая 4 с (2)`, затем `(3)` и так далее. Ctrl+C останавливает обработку. Уже готовые файлы остаются в выходной папке. Для закрытия окна после завершения нажмите Enter.

Громкость поднимается от нуля по косинусной S-кривой и достигает исходного уровня через 4 секунды. В коротком треке кривая действует на имеющийся участок. Для прослушивания берите готовый файл из выходной папки.

Исходные расширение, аудиокодек, частота дискретизации, число каналов и разрядность сохраняются. Для сжатого аудио программа берёт целевой битрейт из исходной дорожки. Если контейнер не хранит номинальный битрейт, как у Opus, программа измеряет средний аудиобитрейт по пакетам. Обработка требует перекодирования. У VBR-файлов и lossless-файлов фактический средний битрейт и размер меняются вместе с аудиоданными. Для VBR точное совпадение среднего битрейта невозможно гарантировать. MP3-теги, включая обложки и служебные ID3-поля, копируются побайтно. Теги остальных форматов и обложки переносятся средствами FFmpeg, поэтому специфичные поля отдельных контейнеров могут измениться.

Программа ищет распространённые аудиорасширения, включая MP3, WAV, FLAC, M4A, AAC, OGG, Opus, WMA, AIFF, WavPack, ALAC и другие. Форматы, для которых у FFmpeg нет обратного кодировщика, например APE, TAK, Musepack и DSD, попадают в отчёт ошибок. AMR также попадает в отчёт ошибок, поскольку автоматическое сохранение исходного режима битрейта для него не поддерживается. Файл с ошибкой не выдаётся за готовый результат.

Внизу окна размещена подпись `by IG`. При наведении на неё один раз проигрывается 3,5-секундная 3D-анимация: золотой блик справа налево, затем возврат к серебру с золотистой правой частью. При уходе курсора логотип сразу возвращается к исходному кадру.

История хранится отдельно от музыки, в `%APPDATA%\LenaDJ\SCurve\folders.json`. Диалог выбора использует встроенный Windows PowerShell и Windows Forms.

## Сборка и проверка

Требуется Go и Python 3. Ресурс иконки `icon_windows_amd64.syso` включён в исходники. Для перерисовки иконки нужен Pillow (`python3 make_icon.py`), затем генератор `github.com/akavel/rsrc@v0.10.2` (`rsrc -arch amd64 -ico icon.ico -o icon_windows_amd64.syso`). Загрузите ZIP `ffmpeg-release-essentials.zip` и одноимённый `.sha256` с https://www.gyan.dev/ffmpeg/builds/ . Этот поставщик указан на https://ffmpeg.org/download.html .

Из корня репозитория выполните `python3 tools/windows-fade/build.py PATH/ffmpeg-release-essentials.zip out/windows-fade/S-curve-4s.exe`.

Тесты с локальным FFmpeg и ffprobe запускаются командой `go -C tools/windows-fade test -v ./...`. Тесты проверяют обработку сигнала, параметры файлов, защиту оригиналов, границу папки, ошибки и остановку.

## Компоненты

Встроены неизменённые FFmpeg и ffprobe из Gyan essentials build 9.1. Лицензия GPLv3 находится в `FFmpeg-LICENSE.txt`. Сведения о конфигурации и компонентах находятся в `FFmpeg-README.txt`. Исходный код соответствующего FFmpeg доступен по https://github.com/FFmpeg/FFmpeg/tree/74e4393595 и https://ffmpeg.org/releases/ffmpeg-9.1.tar.xz . Исходный код этой оболочки находится в `tools/windows-fade` репозитория Lena DJ.

## macOS

Для Mac есть отдельное автономное приложение с тем же движком, встроенными FFmpeg/ffprobe и иконкой. Оно поддерживает Intel и Apple Silicon; выбор и перетаскивание папки, ход обработки и остановка доступны в самом окне. Сборка и инструкция: `../macos-fade/README.md`.

## Обновления и запуск

С версии 1.2.0 при открытии выполняется фоновая проверка GitHub Releases `CanICallYouJim/s-curve-4s`. В окне видны текущая версия и плашка «Обновить» при наличии новой. Установка — только по кнопке; без интернета обработка доступна. Загруженный EXE проверяется по SHA256 и сохраняется в `%APPDATA%\IG\SCurve\updates`. Старый EXE при следующем открытии запускает уже установленную новую версию из этого хранилища.

Повторный запуск открывает существующее окно, а не создаёт ещё один интерфейс. Окно работает отдельно от консольного процесса обработки; значка в трее нет. Если окно не открылось за 45 секунд или произошла ошибка, программа показывает сообщение и сохраняет диагностику в `%LOCALAPPDATA%\LenaDJ\SCurve\startup.log`.

## Ограничение кеша с 1.2.2

После успешного открытия новой версии в кеше остаются текущая версия и одна предыдущая рабочая. Запущенные старые версии сохраняются дополнительно, пока используются; очистка не затрагивает музыку, результаты, настройки и историю папок. Если метаданные повреждены или безопасность удаления не подтверждена, очистка пропускается.

Обновление и очистка используют общую блокировку. Подтверждённо принадлежащие программе брошенные загрузки старше 24 часов удаляются при следующем запуске; свежая или активная загрузка не удаляется. Неизвестные временные каталоги старых клиентов и общий TEMP автоматически не чистятся.

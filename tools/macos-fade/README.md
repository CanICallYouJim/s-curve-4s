# S-кривая 4 сек для macOS

Автономное приложение для macOS 13 и новее, Intel и Apple Silicon. FFmpeg и ffprobe находятся внутри; Homebrew, Терминал и интернет для обработки не нужны.

1. Распакуйте ZIP и перенесите приложение «S-кривая 4 сек» в удобное место, например «Программы».
2. Откройте приложение. Перетащите одну папку с музыкой в окно либо выберите через «Обзор…» или из списка шести последних папок. Можно бросить папку на иконку приложения в Finder/Dock. Это только подставляет путь.
3. Нажмите «Обработать». Ход обработки появится в окне. «Остановить» завершает текущую обработку без публикации недописанного файла; готовые треки сохраняются.
4. Во время обработки виден журнал. Нажмите «Результаты», чтобы открыть новую подпапку `S-кривая 4 сек`, или «Другая папка», чтобы выбрать следующие треки. Подробности и ошибки находятся в `Отчёт.txt`.

Приложение имеет локальную подпись, но не заверено Apple Developer ID. Если macOS заблокирует первый запуск загруженной копии, разрешите его в «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

Поиск только в выбранной папке, без подпапок. Оригиналы не меняются. Повторная обработка создаёт `S-кривая 4 сек (2)`, `(3)` и далее. Движок тот же, что в Windows: косинусная S-кривая от нуля до исходного уровня за 4 секунды. Расширение, исходный кодек, частота дискретизации, каналы и разрядность сохраняются. Целевой битрейт берётся из исходной дорожки; фактический средний битрейт VBR/lossless и размер меняются после перекодирования. MP3-теги копируются побайтно, метаданные других форматов переносятся FFmpeg. Форматы без кодировщика, включая APE, TAK, Musepack, DSD и неподдерживаемый режим AMR, отмечаются ошибкой без выдачи готового файла.

Подпись `by IG` использует утверждённый размер 48 логических пикселей и анимацию 3,5 секунды по наведению. При уходе курсора возвращается первый кадр. Системная настройка уменьшения движения отключает проигрывание.

История папок: `~/Library/Application Support/LenaDJ/SCurve/folders.json`. Сборка универсальная, нативная для Intel и Apple Silicon.

## Сборка

Нужны macOS, Xcode Command Line Tools (Swift/AppKit/iconutil/codesign), Go и Python 3. Скачайте четыре ZIP FFmpeg/ffprobe 9.1 с SHA256, указанные в `THIRD-PARTY.md`, в `TOOLS/amd64` и `TOOLS/arm64`, распакуйте исполняемые файлы рядом с архивами. Сборщик проверяет SHA256 архивов, соответствие распакованных файлов и отсутствие зависимостей от Homebrew.

`python3 tools/macos-fade/build.py TOOLS out/macos-fade/S-кривая\ 4\ с.app`

Базовые native проверки: `out/macos-fade/S-кривая\ 4\ с.app/Contents/MacOS/SCurve --self-test`.

Go-движок принимает `--folder ПАПКА --tools ПАПКА_С_FFMPEG --result ПУТЬ_JSON`; результат содержит `output`, `done`, `failed`, `error`. Коды выхода: 0 — всё обработано, 1 — ошибка или частичный результат, 2 — остановка. Без аргументов Windows показывает свой диалог. Новая логика отделена от проверки музыкальной библиотеки.

## Обновления

С версии 1.2.0 при открытии программа в фоне проверяет GitHub Releases `CanICallYouJim/s-curve-4s`, показывает свою версию и кнопку «Обновить», если опубликована новая. Установка происходит по кнопке и не начинается во время обработки музыки. ZIP проверяется по SHA256, новая версия устанавливается отдельно в `~/Library/Application Support/IG/SCurve/updates`, затем запускается. Прежний .app остаётся лаунчером и при следующем открытии переходит к установленной новой версии. Без сети можно продолжать обработку. Публикация версий описана в `../scurve-release/README.md`.

## Ограничение кеша с 1.2.2

После успешного открытия новой версии в кеше остаются текущая версия и одна предыдущая рабочая. Запущенные старые версии сохраняются дополнительно, пока используются; очистка не затрагивает музыку, результаты, настройки и историю папок. Если метаданные повреждены или безопасность удаления не подтверждена, очистка пропускается.

Обновление и очистка используют общую блокировку. Подтверждённо принадлежащие программе брошенные загрузки старше 24 часов удаляются при следующем запуске; свежая или активная загрузка не удаляется. Неизвестные временные каталоги старых клиентов и общий TEMP автоматически не чистятся.

# S-кривая 4 сек · by IG

Плавное начало музыкальных треков: громкость поднимается по S-кривой от нуля до исходного уровня за 4 секунды.

## Скачать

- [Windows 10/11 x64 — EXE](https://github.com/CanICallYouJim/s-curve-4s/releases/latest/download/S-curve-4s-Windows.exe)
- [macOS 13+ — Intel и Apple Silicon](https://github.com/CanICallYouJim/s-curve-4s/releases/latest/download/S-curve-4s-macOS.zip)
- [Все версии](https://github.com/CanICallYouJim/s-curve-4s/releases)

Перетащите папку в окно или выберите её через «Обзор…», затем нажмите «Обработать». Программа запоминает шесть последних папок. Поиск идёт только в выбранной папке, без подпапок. Копии появляются в новой подпапке «S-кривая 4 сек»; исходники не меняются.

FFmpeg встроен: для обработки не нужны интернет, Homebrew или отдельная установка кодеков. Сохраняются исходные расширение, кодек, частота, каналы и разрядность; целевой битрейт берётся из исходной дорожки. Перекодирование изменяет фактический средний битрейт VBR/lossless. Форматы без доступного обратного кодировщика отмечаются в отчёте ошибок.

## Обновления

При открытии программа проверяет опубликованную версию в GitHub Releases, показывает текущую версию и плашку «Обновить», если доступна новая. Установка запускается только по кнопке. Новая версия загружается в отдельную папку, проверяется по SHA256 и запускается. Прежний файл продолжает работать как лаунчер для установленной версии. При недоступной сети можно продолжать пользоваться программой.

Приложение открывает обычное окно и не использует значок в системном трее. Windows не запускает несколько копий интерфейса от повторных двойных кликов. Ошибка открытия окна показывается явно и сохраняется в `%LOCALAPPDATA%\LenaDJ\SCurve\startup.log`.

Mac-приложение подписано локальной ad-hoc подписью, без заверения Apple Developer ID. При блокировке загруженной копии разрешите запуск в «Системные настройки → Конфиденциальность и безопасность».

С версии 1.2.2 кеш ограничен текущей и одной резервной версией; работающие старые экземпляры защищены. Подтверждённо брошенные загрузки старше суток очищаются при следующем запуске. Музыка, настройки и история не удаляются.
